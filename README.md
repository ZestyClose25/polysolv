# Polysolv

Physics-informed two-tower GNN that recommends a **green solvent** to selectively dissolve **polystyrene (PS)** from a **PS/PET** mixture while PET stays solid.
It predicts the Flory–Huggins parameter χ(T) = A + B/T as a correction to a Hansen-parameter prior and derives solubility from χ.

See `docs/build_plan.md` (tasks + progress log) and `docs/architecture.md`.

## Setup (Windows, from repo root)
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cu130   # CUDA build (or plain `pip install torch` for CPU)
pip install -e .[dev,baselines]
```

## Commands
```powershell
python -m scripts.build_dataset            # data/raw -> data/processed
python -m baselines.hsp_ranking            # Hansen baseline   -> results/hsp_baseline.json
python -m baselines.xgb_baseline           # XGBoost baseline  -> results/xgb_baseline.json (~4 min)
python -m scripts.run_training             # Polysolv stage 1  -> results/polysolv_stage1.json (~8 min on GPU)
python -m scripts.run_training --no-physics   # plain two-tower GIN baseline -> results/gin_plain.json
python -m scripts.compare_models           # results/comparison.md (all models, Zhou test + external test)
python -m scripts.run_lopo                 # leave-one-polymer-out (~16 min per polymer) -> results/lopo.md; resumable with --polymers
python -m scripts.run_lopo --no-physics --polymers PS PET   # same for the plain GIN
pytest -q
```

## Data sources
| File | Source | Use |
|---|---|---|
| `data/raw/zhou2023/d3gc00404j1_suppl.xlsx`, `d3gc00404j2_suppl.pdf` | Zhou et al., *Green Chem.* 2023, 25, 4402–4414, DOI [10.1039/D3GC00404J](https://doi.org/10.1039/D3GC00404J), ESI | Training labels (COSMO-RS wt%, 8 polymers × 1007 solvents × 2 T) |
| `data/raw/kern2022/` | Kern et al., *PCCP* 2022, DOI [10.1039/D2CP03735A](https://doi.org/10.1039/D2CP03735A), ESI + GitHub `Ramprasad-Group/polymer_in_solvent_solubility_modeling` | **Not used** (labelled pairs not public) |
| `data/external/polymer_props.csv` | Hand-built: Polymer Handbook values, Hansen handbook (2nd ed.) averages via accudynetest.com, Materials 2018, 11, 1529 | Polymer descriptors, Hansen prior |
| `data/external/exp_test.csv` | Zhou 2023 Table 3; Polymer Handbook solvent / non-solvent lists | External experimental test set (never trained on) |
| `data/external/green_solvents.csv` | CHEM21 solvent selection guide (Prat et al., *Green Chem.* 2016, 18, 288) | Screening filter |

## Training logs
Every training run writes `results/training_logs/<run>.log` (config, head init, one line per epoch with
train/val loss, val MAE/R², learning rate, time), `<run>_history.csv` (same numbers as a table) and
`<run>_curves.png` (loss and val R² curves). Checkpoints go to `checkpoints/` (git-ignored).

`data/raw/` is never modified. `data/processed/` is regenerated by `scripts/build_dataset.py`.
